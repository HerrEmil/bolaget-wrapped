# Bolaget Wrapped

An unofficial, Spotify-Wrapped-style recap of your year at Systembolaget. Drop a bank export (CSV, Excel or pasted rows) and get a story of visits, favourite weekday, biggest month, holidays, payday habits and a shareable card. Everything is computed in the browser; nothing is uploaded.

Not affiliated with Systembolaget or Spotify.

- `npm test` runs the parser and stats tests.
- `npm run dev` serves the site at http://localhost:8080 (add `#exempel` for the demo year).
